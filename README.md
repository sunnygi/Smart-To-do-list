# 📝 To-Do List (Python)

A simple **To-Do List** application built using Python. It allows users to **add, remove, and view tasks**, helping them stay organized.

## 🚀 Features
✅ Add tasks to the list  
✅ Remove tasks when completed  
✅ View all tasks anytime  
✅ Simple and user-friendly
